### 1. AWS 给 AgentCore Gateway 补齐分层工具权限治理
- **分类**：Agent·安全治理｜**影响指数**：8.5｜**置信度**：高（文档能力）/ 中等（生产泛化）
- **[已知]** AWS 给出 MCP 工具接入的三阶段治理架构：JWT 身份验证、Cedar RBAC/ABAC、`LOG_ONLY` 到 `ENFORCE` 灰度、PII 过滤、CloudTrail/CloudWatch 审计、按身份和工具限流，并用 OPA 补充时间窗与工单等复杂规则。

- **为什么重要**：企业 Agent 从“能调用 MCP”进入“谁能在什么参数下调用哪个工具、事后能否追责”的治理阶段。

### 2. AWS 用小模型压缩检索上下文，报告 RAG 成本降 33%
- **分类**：算法·RAG｜**影响指数**：8.2｜**置信度**：高（方法）/ 中等（性能泛化）
- **[已知]** AWS 在检索与最终回答之间增加小模型逐字证据抽取。作者 benchmark 报告：压缩方案使主模型输入 token 减少 8.6 倍、单查询成本下降 33%；叠加 rerank 后分别为 10.1 倍和 36%，正确性评分与 baseline 相差不超过 0.07。
- **[推断]** 当长上下文输入是主要成本时，该模式可能有效；但额外模型调用会增加延迟，而且结果取决于语料、查询、模型价格比和压缩提示。
- **为什么重要**：它不靠更便宜的大模型，而是在昂贵推理前删除无关证据，直接改变 RAG 的成本结构。
- **来源**：[AWS 官方](https://aws.amazon.com/blogs/machine-learning/reduce-rag-costs-on-amazon-bedrock-with-query-aware-compression/)（2026-08-21 16:59:15Z）
