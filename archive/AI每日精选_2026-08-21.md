### 1. AWS 为 Bedrock 上的 GPT-5.6 开放跨区推理
- **分类**：平台·模型服务｜**影响指数**：8.6｜**置信度**：高
- **[已知]** AWS 宣布 GPT-5.6 Sol、Terra、Luna 可通过 cross-Region inference 在 25 个以上 AWS Region 调用，提供美国地理范围与全球两类 inference profile；三款模型支持文本、图像输入、百万 token 上下文、推理模式、服务端工具调用与 prompt caching。
- **[推断]** 跨区容量池可缓解单区容量瓶颈，但官方公告没有证明具体业务的延迟、成本或可用性改善。
- **为什么重要**：同一模型开始从“单区可用”转向“跨区容量调度”，直接影响企业 Agent 的吞吐、数据驻留边界与容灾设计。
- **来源**：[AWS 官方](https://aws.amazon.com/blogs/machine-learning/introducing-cross-region-inference-for-openai-gpt-5-6-models-on-amazon-bedrock/)（2026-08-20 21:46:03Z）

### 2. Liquid AI 为 LFM2.5 发布 DSpark 推测解码模型
- **分类**：算法·边缘推理｜**影响指数**：8.4｜**置信度**：高（发布）/ 中等（性能泛化）
- **[已知]** Liquid AI 为 LFM2.5-1.2B-Instruct、2.6B、8B-A1B 发布 DSpark draft checkpoints，并给出 llama.cpp 与 SGLang 接入方式。官方 batch=1 测试报告 H100 最高 3.18 倍、M4 Max 最高 2.87 倍吞吐增益，2.6B function calling 平均延迟下降 57%。
- **[推断]** 这把昨日的 4-bit 量化路线推进到“不改变 greedy 输出的推测解码”；但数字来自厂商指定硬件与数据集，不能外推到所有生产负载。
- **为什么重要**：本地 Agent 的瓶颈从“模型能否装下”转向“工具调用能否足够快”，DSpark 给出了可下载、可接入现有运行时的加速路径。
- **来源**：[Liquid AI / Hugging Face 原文](https://huggingface.co/blog/LiquidAI/lfm25-dspark)（2026-08-20 16:52:57Z）

### 3. AWS AgentCore 把自然语言规则编译为 Dogwood 策略
- **分类**：Agent·安全治理｜**影响指数**：8.0｜**置信度**：高（能力）/ 中等（普适可靠性）
- **[已知]** AWS 文档展示 Policy Authoring 如何结合自然语言政策与 MCP 工具 schema，生成默认拒绝的 Dogwood 策略；示例覆盖参数上限、时间窗口、前置身份验证与累计额度。
- **[推断]** 这能把 Agent 治理从 prompt 约束推进到工具调用层的可执行规则，但少量示例不能证明任意政策文本都能被正确形式化。
- **为什么重要**：高权限 Agent 的核心问题不是“会不会遵守提示”，而是越权调用能否被独立执行层拒绝；该能力直接针对这一根因。
- **来源**：[AWS 官方](https://aws.amazon.com/blogs/machine-learning/authoring-dogwood-policies-from-natural-language-in-amazon-bedrock-agentcore/)（2026-08-20 16:31:28Z）

### 4. Microsoft Research 发布 Skala 1.1，并扩大计算化学软件接入
- **分类**：研究·AI for Science｜**影响指数**：7.8｜**置信度**：高（发布与接入）/ 中等（性能泛化）
- **[已知]** Skala 1.1 的训练数据约为前版 2.5 倍，已可在 CP2K 使用，并在接入 Psi4、FHI-aims、ORCA 与 VASP。作者报告其在 GMTKN55 的 55 类任务中有 32 类排名第一，并发布持续更新的性能 benchmark。

- **为什么重要**：机器学习泛函开始进入科学家现有 DFT 工作流，事件从“研究原型”推进到“多软件生态集成”。
