HyperPod 缓存将扩容提速约六成

来源：AWS What's New · AWS 文档2026-09-12 02:25 +08可信度：中高
Lead1 / 3

AWS 为 SageMaker HyperPod 推出通用可用的模型与镜像缓存，使推理 Pod 从分钟级缩短到秒级启动。

AWS 在 57–145GB 模型测试中称扩容约快 60%，镜像拉取时间减少 97%。

IMPACT 8.4
Analysis2 / 3

大模型在线推理的成本不仅在每 token；突发流量下的冷启动决定容量利用率和服务可用性。

  • 本地 NVMe 权重缓存减少重复网络下载。
  • 镜像预拉取降低弹性扩容等待时间。
  • 未命中缓存仍回退原始来源，降低卡死风险。

主要来源AWS What's New · AWS 文档
可信度中高
